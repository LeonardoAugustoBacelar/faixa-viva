Metodologia

Todos os valores desta página vêm de uma busca real, feita uma única vez, via Copernicus Data Space Ecosystem (Statistical API para NDVI e radar, Process API para as imagens da galeria do dashboard) — não há chamada de API em produção; os dados ficam gravados de forma estática no protótipo. NDVI é calculado a partir das bandas B04/B08 do Sentinel-2 (com máscara de nuvem via banda SCL); o radar usa a banda VV do Sentinel-1 GRD, modo IW, sem correção atmosférica adicional além do processamento padrão Gamma0 terreno. "Cobertura" nesta página mede disponibilidade de leitura por janela de 15 dias, não precisão do dado — não substitui a calibração de campo que o protótipo já assume como pendência (ver painel de detalhe de cada trecho no dashboard).
